# Operadores Aritméticos

| Operador | Significado |
| --- | --- |
| **+** | Adição |
| **-** | Subtração |
| * | Multiplicação |
| **/** | Divisão |
| **%** | Resto da divisão ("mod") |

## Precedência:

| 1° Lugar | 2° Lugar |
| --- | --- |
| * / % | + - |

# Uso de Parênteses 

O parênteses () define a prioridade da operação 

## Exemplo:

| Uso de Parênteses | Sem o Uso |
| --- | --- |
| (10 + 5) / 5 = 3 | 10 + 5 / 5 = 11 |
