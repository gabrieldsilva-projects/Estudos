## 📚 Sobre o curso

Este curso foi pensado para levar você do zero até um nível avançado em Java, com foco em desenvolvimento profissional e prática.

A abordagem combina:

- Fundamentos da linguagem
- Programação Orientada a Objetos
- Estruturas de dados
- Boas práticas
- Ferramentas usadas no mercado

O conteúdo acompanha uma jornada gradual, com explicações didáticas, exemplos práticos e projetos reais, e está alinhado às versões modernas do Java.

## 🎯 Objetivo

Aprender Java de forma sólida e aplicada, construindo uma base forte em POO e nas tecnologias relevantes para o mercado de trabalho.

> Além da sintaxe, você aprenderá conceitos e padrões que fazem diferença na prática profissional.

## 🧭 O que será abordado

### Fundamentos e lógica de programação

- Lógica de programação e algoritmos
- Sintaxe da linguagem Java
- Classes, atributos e métodos
- Construtores, sobrecarga e encapsulamento

### Orientação a objetos e estruturas de dados

- Arrays e coleções
- Enumerações e composição
- Herança, polimorfismo e interfaces
- Tratamento de exceções
- Generics
- Programação funcional e expressões lambda
- Stream API
- Manipulação de arquivos

### Ferramentas e frameworks para o mercado

- JDBC para acesso a dados com SQL
- JavaFX para interface gráfica
- Git e GitHub para versionamento
- Spring Boot para desenvolvimento web
- JPA / Hibernate para mapeamento objeto-relacional (ORM)
- Maven para gerenciamento de dependências
- Spring Data JPA
- Spring Data MongoDB

## 👥 Para quem é este curso?

- 🟢 Iniciantes que querem aprender Java do zero
- 🟢 Desenvolvedores que desejam reforçar seus conhecimentos
- 🟢 Pessoas que buscam uma formação prática e aplicada
- 🟢 Quem pretende atuar com Java, Spring Boot e backend
