# Java Completo - Programação Orientada a Objetos + Projetos

## Professor
Nelio Alves

# Plataforma 
Udemy 

## Visão geral
Atualizado: Java 25 e Spring Boot 4

Este curso foi pensado para levar você do zero até um nível avançado em Java, com foco em desenvolvimento profissional e prática. A abordagem combina fundamentos da linguagem, programação orientada a objetos, estruturas de dados, boas práticas e ferramentas usadas no mercado.

O conteúdo é 100% compatível com a versão LTS atual do Java e acompanha uma jornada gradual, com explicações didáticas, exemplos práticos e projetos reais.

## O que será abordado

### Fundamentos e lógica de programação
- Lógica de programação e algoritmos
- Sintaxe da linguagem Java
- Classes, atributos e métodos
- Construtores, sobrecarga e encapsulamento

### Orientação a objetos e estruturas de dados
- Estruturas de dados: arrays e coleções
- Enumerações e composição
- Herança, polimorfismo e interfaces
- Tratamento de exceções
- Generics
- Programação funcional e expressões lambda
- Stream API
- Manipulação de arquivos

### Ferramentas e frameworks para o mercado
- JDBC para acesso a dados com SQL
- JavaFX para interface gráfica
- Git e GitHub para versionamento
- Spring Boot para desenvolvimento web e aplicações Java
- JPA / Hibernate para mapeamento objeto-relacional (ORM)
- Maven para gerenciamento de dependências
- Spring Data JPA
- Spring Data MongoDB

## Objetivo do curso

Aprender Java de forma sólida e aplicada, com uma base forte em POO e em tecnologias relevantes para o mercado de trabalho. O curso foi estruturado para ajudar você a entender não apenas a sintaxe, mas também os conceitos e padrões que fazem diferença na prática profissional.

## Para quem é este curso?

- Iniciantes que querem aprender Java do zero
- Desenvolvedores que desejam reforçar e aprofundar conhecimentos
- Pessoas que buscam uma formação prática e aplicada em Java
- Quem pretende trabalhar com Java, Spring Boot e desenvolvimento backend
