# 📘 Expressões Comparativas

> Material de estudo baseado nas aulas do **Prof. Dr. Nélio Alves**.

As expressões comparativas relacionam dois valores e retornam um resultado do tipo **`boolean`**: `true` ou `false`.

| Operador | Significado | Exemplo | Resultado |
| :---: | :--- | :---: | :---: |
| `==` | Igual a | `10 == 10` | `true` |
| `!=` | Diferente de | `10 != 5` | `true` |
| `>` | Maior que | `10 > 5` | `true` |
| `<` | Menor que | `5 < 10` | `true` |
| `>=` | Maior ou igual a | `10 >= 10` | `true` |
| `<=` | Menor ou igual a | `5 <= 10` | `true` |

## 💡 Exemplo em Java

```java
int idade = 18;

boolean maiorDeIdade = idade >= 18;
System.out.println(maiorDeIdade); // true
```
