 # 📘 Expressão condicional Ternária 

> Material de estudo baseado nas aulas do **Prof. Dr. Nélio Alves**.

# Conceito

Estrutura opcional ao if-else, usada para escolher um **VALOR** com base em uma condição.

## Sintaxe

```java
( condição ) ? valor_se_verdadeiro : valor_se_falso
```

## Exemplos:

**Exemplo 1:**
```java
(2 > 4) ? 50 : 80
```

**Saída:**
```txt
80
```

**Exemplo 2:**
```java
(10 != 3) ? "Maria" : "Alex"
```

**Saída:**
```txt
Maria
```
